## 🛠️ Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/dameldesign/danielekundayo-portfolio-2.0.git
    ```

2. Install dependencies:
    ```bash
    yarn install
    ```

3. Run the development server:
    ```bash
    yarn dev
    ```

5. Open [http://localhost:3000](http://localhost:3000)
